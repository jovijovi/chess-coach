临时 AppArmor 配置，三个平台均通过；RC.1 源码标签保持不变。

## 补充本机验证

- 在独立用户目录中，使用现有 GitHub 身份，通过 Codex 添加
  `jovijovi/chess-coach --ref marketplace-preview` 私有源。安装所得的 GitHub
  插件包又通过一轮离线十回合原生验收，包括分析、重启、PGN 和重装。
- 原生 marketplace 刷新、重装和通过 `plugin-v0.2.0-rc.2` 安装均在独立用户目录通过。重试期间私有 Git 传输较慢，生命周期检查采用 HTTP/1.1 和有时限的传输等待。
- 现有 0.1.0 棋谱的隔离副本通过旧运行目录识别、运行文件清理、完整历史恢复、
  语言偏好保留和 PGN 重放检查；原始棋局及 personal 安装保留。
- 检查了中英文手册的桌面与窄屏显示、保持章节的语言切换、新增清理命令的搜索
  和 Escape 关闭。网站继续默认英文。

## 验证范围与后续步骤

原生 Codex 证据来自 CLI/app-server API 和真实引擎结果，尚未在每个平台使用
已登录的桌面模型账户进行人工对话。自动化讲解检查覆盖传给对话的局面、版本、
分数表示及合法变化线，不评价模型生成的自然语言讲解质量。

仓库保持私有。获得所有者明确公开确认后，准备并发布稳定版 `v0.2.0`，
再以无 GitHub 凭据的环境验证安装。预览版不自动升级，不发布 npm，
不注册远程 MCP，也不提交官方目录。
